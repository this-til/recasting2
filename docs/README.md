# Recasting 玩家手册

本手册面向玩家：说明相对 SlashBlade 原版改了什么，以及名刀、拔刀术（SA）、特殊效果（SE）、层数效果各自怎么用、数值多少。

怎么读：

- **默认值**：下文数字取自模组当前默认配置；标了「可在配置改」的项，以游戏内配置为准。
- **时间**：正文优先写秒；需要对照引擎时，**20 tick = 1 秒**。
- **伤害倍率**：未写「%」的小数（如 **0.3**）表示相对该次攻击基础伤害的倍率。
- **配方与进度**：合成与结晶升级链请用 JEI、进度查看；各刀出厂绑定见 [名刀图鉴](#名刀图鉴)。

## 与原版的差异（速查）

### 改动原版

- 亡灵杀手 / 节肢杀手：对对应种族，斩击每级 **+5%**
- 火焰附加：仅斩击，每级 **+3%** 火焰伤害
- 火矢：仅幻影剑，每级 **+3%** 火焰伤害
- 力量：仅幻影剑，每级 **+5%**；没有力量则无法放出幻影剑技
- 横扫之刃：挥刀范围每级 **+0.2**
- 集中评分 0→6：最多 **+10%**
- 精炼加成：**300%** × 精炼 / (精炼 + **1000**)；精炼 >1000 / >10000 再各 **+10%**
- 击杀 >1000 / >10000 / >100000 / >1000000：分别 **+10% / +10% / +5% / +5%**
- 幻影剑基础伤害倍率默认 **0.1**；次元斩带出的斩击默认 **0.1**
- 补全了原版 SA 的简介文字
- 未安装 srelic（SlashBlade Relic）时，幻影剑输入由本模组接管

### 本模组新增

- 大量名刀、拔刀术与特殊效果（详见后文图鉴）
- 铁砧铭刻 SE 结晶：普通最多 **4**、特殊最多 **1**
- 杀敌可掉：耀魂、基础火、庸魂立方体、SE 结晶、「回到未来计划」SA 宝珠
- 刀架上用未写入 SA 的耀魂宝珠切换「幻影剑 / 幻影飞刃」
- 层数效果（灵魂燃烧、电离、电涌等）

## 战斗与数值

伤害会随附魔、精炼、击杀数、集中评分，以及攻击类型（斩击 / 幻影剑 / 次元斩 / 剑气 / 闪电）共同变化。部分附魔只对特定攻击生效。

### 附魔

| 附魔 | 作用对象 | 默认 |
| ---- | -------- | ---- |
| 亡灵杀手 | 对亡灵的斩击 | 每级 **+5%** |
| 节肢杀手 | 对节肢的斩击 | 每级 **+5%** |
| 火焰附加 | 仅斩击，额外火焰伤害 | 每级 **+3%** |
| 火矢 | 仅幻影剑，额外火焰伤害 | 每级 **+3%** |
| 力量 | 仅幻影剑 | 每级 **+5%** |
| 横扫之刃 | 挥刀判定范围 | 每级 **+0.2** |

### 集中评分

集中等级从 C 到 SSS，伤害加成从 **0%** 线性升到最多 **+10%**。满评即约 **+10%**。

### 精炼

加成 = **300%** × 精炼 / (精炼 + **1000**)

另有两档里程碑（与上式**独立叠乘**）：

- 精炼 **>1000**：**+10%**
- 精炼 **>10000**：再 **+10%**

**修复：** 原版在附魔值极高时，单次精炼增加的荣耀值可能算成负数；本模组已修正。

### 击杀数

刀上累计击杀跨过门槛时加伤（各档**独立叠乘**）：

- **>1000**：**+10%**
- **>10000**：再 **+10%**
- **>100000**：再 **+5%**
- **>1000000**：再 **+5%**

四档可同时生效。满档合计 **+30%**（叠加在精炼等其它加成之外）。

### 攻击距离

部分名刀自带更长触及。挥刀判定还会被横扫之刃放大。断刀时触及仍按原版断刀规则缩短，再按该刀的距离倍率缩放。

### 幻影剑

放出条件：

- 刀为妖化（bewitched）状态，未损坏、未被封印
- 刀上有 **力量** 附魔（任意级）
- 基础射击消耗原版「召唤剑」耀魂费用；花式剑技消耗原版「召唤剑技」耀魂费用（以 SlashBlade 配置为准）

若刀已由 srelic 接管，仍使用原版幻影剑操作；下列手势仅作用于本模组接管的刀。

使用键即原版召唤剑键（默认多为鼠标中键，以键位设置为准）。点按立即射出基础幻影剑；按住约 **0.5 秒** 后松手，才会触发花式剑技。

| 操作 | 效果 |
| ---- | ---- |
| **点按使用** | 基础幻影剑。伤害倍率 **0.1** |
| **按住约 0.5 秒**（站立不潜行，或不在潜行中移动） | **回旋剑**：环绕自身旋转，再按一次放飞。数量 **6**，集中评分达 S 则为 **8**。半径 2，转速 16°/tick |
| **潜行 + 后退 + 使用** | **风暴剑**：环绕**锁定目标**收缩。数量同上（6 / S 评 8）。需已锁敌 |
| **潜行 + 前进 + 使用**，且最近 **1 秒内未按后退** | **急行幻影剑**：分列两侧依次射出，6 / S 评 8 把，速度 3.5 |
| **潜行 + 前进 + 使用**，且最近 **1.5 秒内按过后退** | **剑雨**：在目标（或身前 5 格）上方 **7** 格处落下，约 **8～9** 把 |

### 幻影飞刃

在刀架台上，用**未写入 SA** 的耀魂宝珠敲刀，可在「幻影剑」与「幻影飞刃」之间切换。生存模式消耗 **1** 颗宝珠。动作栏与物品提示会显示当前形态。

幻影飞刃会追踪目标：有潜行锁敌时追锁敌，否则在视锥内寻敌。寻敌更新间隔 **0.5 秒**。

## 锻造与结晶

铁砧是本模组改刀的主入口。结晶、火、变体、耀魂宝珠都在这里使用。

### 铭刻上限

默认：一把刀最多 **4** 个普通 SE + **1** 个特殊 SE。

- 特殊 SE 可在铁砧上直接换成另一种特殊 SE
- 创造模式不受数量限制
- 配置项「解除 SE 铭刻限制」打开后，普通与特殊均不再限数量

普通 SE 默认可升到 **5** 级。特殊 SE 一般只有 **1** 级，占用特殊槽。

### 刀 + SE 结晶

| 操作 | 规则 |
| ---- | ---- |
| **铭刻** | 刀上尚无该 SE，且未顶满对应上限时，写入结晶上的 SE |
| **升级** | 同一种 SE，结晶等级必须**高于**刀上当前等级 |
| **抹除普通 SE** | 用 **0 级** 结晶，去掉刀上已有的该普通 SE |
| **特殊 SE** | 仅用 **1 级** 结晶铭刻或替换；无 0 级抹除。要去掉特殊 SE，用渊寂火 / 聚散变体 |

### 刀 + 渊寂火

烧掉刀上**第一个**特殊 SE，刀本身保留。适合只想卸掉特殊 SE、不毁刀时使用。

### 刀 + 聚散变体

抽出刀上**第一个**特殊 SE，变成 1 级结晶；**刀会销毁**。适合把特殊 SE 回收成结晶时使用。

### 刀 + 耀魂宝珠

抽出刀上的 SA，写入右侧耀魂宝珠。**刀会销毁**；若宝珠原先已有 SA，会被覆盖。

在刀架上用**未写入 SA** 的耀魂宝珠敲刀，会切换射击形态，见 [幻影飞刃](#幻影飞刃)。

### 合成时 SE 的继承

用工作台把刀做成下一把时：

- **特殊 SE**：若新刀出厂自带特殊 SE，用新刀的；否则从材料刀继承
- **普通 SE**：材料刀与新刀出厂列表合并；同一种取更高等级；总数仍最多 **4** 个。超出上限时，优先丢掉「新刀出厂多出来、材料刀没有」的那些普通 SE

### λ 变体

- 中文名前缀 `^`
- 成长链会提高杀敌数 / 精炼门槛
- 对应 SA / SE 的数值通常更高，详见 [名刀图鉴](#名刀图鉴)

## 掉落

手持拔刀剑击杀生物时掉落。若有耀魂背包，优先进入背包。带冷却的类别在冷却期内不会再次掉落。

下列概率与冷却均为默认值，**可在配置改**。

| 掉落 | 概率 | 冷却 |
| ---- | ---- | ---- |
| 破碎的耀魂 | **8%** | 无 |
| 耀魂碎片 | **4%** | 无 |
| 带 1 级随机附魔的破碎耀魂 | **2%** | 无 |
| 任意基础火 | **1%** | **3 分钟**（3600 tick） |
| 任意庸魂立方体 | **0.1%** | **9 分钟**（10800 tick） |
| 白名单内 1 级 SE 结晶 | **0.05%** | **2 小时**（144000 tick） |
| 白名单内 SA 耀魂宝珠 | **0.05%** | **2 小时**（144000 tick） |

附魔碎魂默认等级 **1**，默认遵守该附魔自身上限（配置可改为无视上限）。

- SE 结晶默认白名单为 **指令映射 / ^指令映射 / 宝具连发 / ^宝具连发**（共 4 个特殊 SE）。
- SA 宝珠默认白名单为「回到未来计划」的 **15** 个 SA，见 [拔刀术图鉴](#拔刀术图鉴)。

掉落到带冷却的物品时，动作栏会提示下次可掉时间。

造成伤害叠层，满 **12** 层打一道闪电并清零。每次 +1 层（与 SE 等级无关）。闪电 **30% / 70%**。每秒掉 1 层。

### 可铭刻特殊 SE

占特殊槽。下列两个不绑在默认刀上，用结晶铭刻。

#### 宝具连发

放 SA 后 **1 秒** 再自动放一次同样的 SA。内置冷却 **3 秒**。

**^宝具连发**：冷却 **2 秒**。

#### 指令映射

主动打出幻影剑技后，按间隔再打同样的技（不扣第二次耀魂）。额外 **2** 次，间隔 **1 秒**。

**^指令映射**：额外 **3** 次。

### 燃烧与持续伤害

#### 灵魂燃烧

业火、燃沫等挂上。每 **1 秒** 造成当前生命 **6%** 的火焰伤害。最多 **99** 层。每秒掉 1 层。层数主要影响「还要烧多久」，单跳伤害不乘层数。

#### 光子灼烧

光子灼痕的激光叠上。最多 **50** 层。每 **0.5 秒** 造成「层数 × 0.1」伤害。约每 **3 秒** 掉 1 层。满层时全伤害最多 **+33%**（由光子灼痕 SE 提供）。

#### 光子灼痕（层）

灼烧期间普通攻击叠这个。最多 **9** 层，满层放短光束（**0.25**）并清零。约每 **5 秒** 掉 1 层。

#### 翠火

云界刃解叠上。最多 **40** 层。每 **1 秒** 固定火焰 **0.5**。满层时目标受到的全部伤害最多 **+40%**（按当前层数比例）。每秒掉 1 层。

#### 黑色玫瑰（层）

黑色玫瑰 SE 的伤害池记账层。每 **0.25 秒** 按当前伤害池结算一次，结算后伤害池变为原来的 **75%**。无单独上限。

#### 茶韵（层）

茶韵 SE 储存伤害的记账层。倒计时结束后，按层数 / 10 一次性放出。

### 增伤层

#### 电离

每层全伤害 **+1%**。最多 **64**。每秒掉 1 层。由电离 SE 叠上。

#### 演算

穷观阵命中叠上。每层目标受伤 **+5%**。最多 **16**。每秒掉 1 层。解算 SE 会消耗 1 层打额外伤害。

#### 红尘

红尘滚滚命中溅射叠上。最多 **160**。满层全伤害 **+33%**（按比例）。另有按层数的固定伤害，每次间隔至少 **0.25 秒**。每秒掉 1 层。

#### 叠晖

有日核时，再被幻影剑打中：打出晖光（**0.15**）、叠 1 层叠晖、消耗 1 层日核。最多 **50** 层。满层时幻影剑伤害再 **+50%**。约每 **5 秒** 掉 1 层。

#### 日核

长空落日 SA 的幻影剑命中叠上（每次 +4）。给叠晖当燃料。不衰减、不封顶（直到被叠晖消耗）。

### 触发计数

#### 破片

幻影剑伤害叠，满 **12** 额外一击。每 **0.25 秒** 掉 1 层。

#### 剑势

幻影剑命中叠，满 **12** 放风暴幻影剑。每 **0.5 秒** 掉 1 层。回旋 SE 触发后进入冷却，冷却期间不叠。

#### 撕裂

次元斩伤害叠，满 **12** 额外一击。每秒掉 1 层。

#### 蓄能

造成伤害叠，满 **12** 落雷。每秒掉 1 层。

#### 雷光

挨雷后叠，最多 **8**。带雷光再挨打吃额外闪电。每秒掉 1 层。

#### 断灭

每出 1 个次元斩 +1，满 **7** 出巨型次元斩。约每 **5 秒** 掉 1 层。

#### 星闪（层）

命中叠，满 **4** 爆发并清速度。不衰减。

#### 金戈（层）

斩击叠，满 **12** 爆发。每 **2 秒** 掉 1 层。

#### 电涌

聚焦能量刃叠，满 **64** 放异界斩切并清零。约每 **5 秒** 掉 1 层。

### 领域与控制

#### 云海

云海 SA 持续期间挂在自身。每秒掉 1 层（层数约等于剩余秒数）。

#### 静滞

被永恒守卫钉住的敌人。期间固定在进入领域时的坐标。每秒掉 1 层。

#### 咒令

万灵寂灭期间挂在自身。持续自损并打出虚空闪电。每秒掉 1 层。

#### 寂灭

万灵寂灭打在敌人身上。最多 **66** 层。每层护甲 **-1%**（乘算，满层大约只剩 34% 护甲）。每秒掉 1 层。

#### 增益压制

万象归元打上。持有期间每 tick 驱散增益。每秒掉 1 层。
